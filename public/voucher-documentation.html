Roles & Access Matrix
Superadmin

System Administrator

  • Create/provision tenant organizations
  • Provision primary HR admin accounts for tenants
  • Edit tenant subscription configurations
  • Bypass registration OTP locks via admin code overrides
  • Monitor system-level cluster statistics
HR Admin

Tenant Administrator

  • Provision employee profiles & accounts
  • Review and audit filed expense claims
  • Approve or reject pending reimbursement requests
  • Execute payroll payouts & financial clearance
  • Assign role-based permissions (RBAC)
Employee

Tenant Staff

  • File new corporate expense claims
  • Upload receipt transaction details
  • View personal expense audit history
  • Preview and print reimbursement voucher sheets
  • Download official voucher document in PDF
Voucher & Tenant API Specifications
GET /api/superadmin/hrs

Fetch list of all active HR Administrator accounts across all tenant organizations.

Response: [ { "id": 105, "username": "acme_hr_admin", "gmail": "hr@acme.com", "mobile": "+919876543210", "role": "ADMIN", "organization": { "id": 12, "name": "Acme Corporations", "orgCode": "HRMS202684279" } } ]
POST /api/superadmin/hr

Provision a new HR Administrator account and assign them to an active organization tenant.

Request Payload: { "username": "acme_hr_admin", "gmail": "hr@acme.com", "mobile": "+919876543210", "password": "SecurePassword123", "orgId": "12" }
PUT /api/superadmin/hr/{id}

Modify an existing HR Admin's contact coordinates or reset their password access.

Request Payload: { "username": "acme_hr_admin_new", "gmail": "new_hr@acme.com", "mobile": "+919876543222", "password": "NewSecurePassword456" // Optional }
DELETE /api/superadmin/hr/{id}

Permanently remove an HR Administrator profile from the workforce registry.

Response: { "message": "HR deleted successfully" }
