SYSTEM ARCHITECTURE
BACKEND REST APIS, FRONTEND ROUTING, AND AUDIT PIPELINES

Zenelait HRMS employs a highly scalable, decoupled client-server architecture model. The client-side dashboard runs on Next.js 14 / Vite, connecting to a multi-threaded Java Spring Boot 3 enterprise backend and a high-performance MySQL/TiDB Cloud relational storage.

TECHNICAL STACK DETAILS
Layer Technology Responsibility
Frontend Client Next.js 14, React, TS, Tailwind CSS Role Dashboards, Real-time Charts, Responsive Layouts
Java Backend Spring Boot 3, Java 21, Hibernate JPA Business Logic, Multi-tenant Data APIs, Security Filters
Messaging Queue Apache Kafka (Port 9092) Asynchronous Audit Logging & Event-driven Logs
Cache Broker Redis Cache (Port 6379) Performance Optimization & API Response Serialization
Database MySQL / TiDB Cloud (Port 4000) Transactional Ledgers, User Accounts, Registry
SECURITY FILTER CHAIN & DECOUPLING

All network interactions use JSON-encoded requests. Spring Security handles endpoint protection, verifying signature validation keys encoded in client-header HTTP bearer authentication tokens on every dispatch.

The backend employs database connection pools (HikariCP) to interact with relational schemas, ensuring fast transactional speeds during high-concurrency workforce attendance logging.

SUBSCRIPTION TIERS
MODULAR CONTROL AND PRICING PLAN MAPPINGS

To provide flexible enterprise SaaS packages, Zenelait HRMS employs an active subscription mapping engine. The features, dashboards, and role dropdowns rendered on login screens are toggled dynamically based on the active client subscription tier.

GROWTH PLAN

Designed for small operations. Unlocks employee clock-in/out registers and self-service. Excludes deep financial ledger control.

PREMIUM PLAN

Adds middle-tier control. Unlocks full HR Manager control panels, Sprint velocity trackers, custom timesheets, and basic payroll metrics.

ENTERPRISE PLAN

Full platform access. Enables the Super Admin console, multi-tenant custom organization settings, Kafka audit streams, and Redis cache tuning.

DATABASE CONFIGURATION & VERIFICATION

The `organizations` table stores subscription levels under the `plan_type` column (STANDARD, MIDLEVEL, ENTERPRISE). When a user authenticates, the handler queries `GET /api/superadmin/organizations` to fetch their tenant context, parsing the subscription plan type to dynamically configure permission matrices on the frontend client.

ROLE-BASED ACCESS
ROLE MAPPING MATRIX AND PERMISSIONS CONTROL

Zenelait HRMS provides strict role-based access control (RBAC) to ensure multi-tenant security isolation. Users are assigned to one of three primary system roles, each unlocking a dedicated set of system controls:

SUPERADMIN

Accesses the platform console. Creates tenant organizations, configures active modules, assigns subscription plan tiers, and provisions primary HR Administrator accounts. Bypasses standard organization scope limits.

ADMIN (HR MANAGER)

Manages the organization roster. Approves or rejects leave requests, schedules project sprints and backlogs, uploads client invoices, processes employee payroll, and updates individual employee matrix keys.

EMPLOYEE (TENANT STAFF)

Maintains attendance clocks, logs timesheets against active projects, files reimbursement expense claims, uploads receipts, and downloads certified PDF payment vouchers.
